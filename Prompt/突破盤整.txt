我會給你股票清單以及日期，若沒給日期就以今天為準。

請幫我搜尋每檔股票在該日期前後的最新公開資訊，包含：
題材、新聞、月營收、財報 / EPS、法說展望、法人買賣超、籌碼變化、成交量、技術面突破狀況與市場資金關注點。

請用「接下來 1～10 個交易日內，短線資金是否可能集中推高」作為主要排序標準。

我的目標不是長期投資，也不是單純看公司基本面，而是找出今天收盤前 / 今天收盤 / 明天開盤最值得短線觀察的標的。

如果是在模擬過去某一天，請只使用該日期當時已知或接近當時已知的資訊，不要用後來才公布的資訊倒推排序。
若有使用事後資訊驗證，請明確標註「事後驗證」。

請務必搜尋每檔股票的最新資訊，不要只憑既有印象、歷史題材或公司長期基本面來排序。
若資訊不足，請明確標註「資訊不足，排序信心較低」。

核心排序原則：
短線排序請嚴格遵守以下優先級。

0. 早盤極強鎖停為最高優先級之一
   - 若某股可確認為「09:10（含）前漲停，且漲停後一路鎖死至收盤」，代表當日短線資金主動攻擊意圖極強。
   - 開盤即以漲停價位開出並一路鎖死至收盤（開盤一字鎖漲停），視為符合上開「09:10 前漲停且一路鎖死至收盤」之早盤極強鎖停。
   - 若漲停後盤中曾打開再鎖回，即使收盤仍漲停，亦不視為第 0 條，應依「4. 當日資金攻擊強度」第 3 項等規則評價，不得套用早盤極強鎖停加權。
   - 在符合上述一路鎖死至收盤條件，且未出現爆量異常、封單快速衰退、重大利空或題材續航明顯不足等弱化訊號前，這類股票的當日資金攻擊加權應高於「具市場主流題材、同族群核心地位，但當日未早盤鎖停」的股票。
   - 即使該股不是市場主流題材，或不是同族群原本核心，只要符合上述早盤鎖停條件，也可排進前段，甚至可排在無早盤鎖停的主流核心股前面。
   - 排序理由中必須明確標註：「早盤極強鎖停加權優先於族群核心地位」。
   - 若兩檔皆符合第 0 條早盤極強鎖停，再依序比較：
     1. 是否開盤一字鎖漲停
     2. 漲停時間（越早越強）
     3. 封單穩定度
     4. 成交量是否健康
     5. 題材續航
     6. 法人 / 主力籌碼
   - 若無法確認是否一路鎖死到收盤，必須標註「鎖停品質需確認」，不可直接假設為最強。

1. 在沒有早盤極強鎖停訊號的情況下，市場主流族群內的核心強勢股，優先於非主流題材個股。
   - 若某股雖有營收、EPS、法說、訂單或展望利多，但不是當下市場主流題材，也沒有帶動族群，不可只因基本面好排到前面。
   - 非主流個股只有在「當日攻擊極強，例如開盤鎖漲停、早盤鎖漲停」時，才可排進前段。
   - 若只是基本面好、公司是龍頭、成交值大，但市場短線資金沒有明顯集中，排名應降低。

2. 同族群內強度是排序核心，不是輔助參考。
   - 題材本身很強，不代表該股短線會漲。
   - 同族群內是否真的被資金選中，才是排序核心。
   - 若同族群已有明顯更強的核心股，該股只能視為次核心、補漲或跟漲。
   - 但若該股符合第 0 條「早盤極強鎖停」條件，則可依第 0 條重新加權，不可只因不是原本族群核心就機械式壓低排名。
   - 若某股不是族群核心，且當日漲幅、成交量、技術型態也不如核心股，排名不得太前。
   - 若某股在同族群內近半年、近 60 日、近 20 日走勢明顯落後核心股，即使題材相同，也應視為資金不偏好或只是補漲。
   - 若某股前面已強很久，近期整理後再次突破，應視為整理後再攻，不要因短期整理而低估。

3. 基本面利多只能作為「續航加分」，不能凌駕於資金強度。
   - 營收、EPS、法說、訂單、漲價、毛利率修復、產品放量等，是判斷續航的重要依據，但不能取代資金強度。
   - 基本面好但非主流、非核心、當日攻擊普通，應排在主流族群核心股與強勢漲停股之後。
   - 營收 / EPS 普通，但若屬於主流族群、當日攻擊強、籌碼集中、題材正在重新定價，仍可排在基本面佳但資金不集中的股票前面。
   - 若只是公司基本面穩健、產業地位高、財報不錯，但當日資金沒有明顯攻擊，不應排太前。

4. 當日資金攻擊強度要明確加權，但不能只看是否漲停。
    當日攻擊強度大致依以下順序判斷：

    1. 開盤一字鎖漲停，且漲停後一路鎖死至收盤
    - 最強，代表資金搶籌意圖極高（屬第 0 條）。
    2. 非一字，但 09:10（含）前漲停，且漲停後一路鎖死至收盤
    - 極強，排序加權可高於無此等早盤鎖停的市場主流核心股（屬第 0 條）。
    3. 09:10 前快速漲停，但盤中曾打開後又鎖回
    - 仍強，但要檢查是否爆量、是否收盤封單穩定。
    4. 放量長紅、收在高點、突破整理，但未漲停
    - 不可低估。
    - 若同時具備明確營收 / EPS / 法說 / 訂單 / 轉單 / 漲價 / 政策題材等預期差，且量能健康，則不可因未漲停而低估；在許多情況下，可排在「盤中或尾盤才硬鎖、但題材續航不足或隔日沖疑慮較高」的漲停股前面。
    - 這類股票請標註為「資金吸籌長紅」、「預期差轉強股」或「整理後再攻股」。
    5. 盤中換手後漲停，且收盤鎖住
    - 算強，但不能自動排在放量長紅收高股前面。
    - 若漲停時間偏晚、成交量爆大量、封單不穩、盤中多次打開，需提高隔日沖風險評價。
    - 若題材續航強、量能健康、收盤封單穩，仍可視為強攻股。
    - 若只是尾盤硬拉鎖漲停，且沒有明確題材 / 基本面 / 法人籌碼支撐，應降權，標註為「疑似隔日沖鎖停」。
    6. 放量上漲但收盤未在高點
    - 視為普通偏強，需檢查是否有上影線與追價失敗。
    7. 爆量開高走低、漲停打開收不回、長上影線、收盤未守關鍵價
    - 明顯降權。

5. 對非主流、非核心個股設排名上限。
   - 若不是市場主流族群，也不是族群核心，除非符合第 0 條「早盤極強鎖停」，否則原則上不排進前 5。
   - 若只是營收 / EPS 好、題材合理，但沒有市場資金集中攻擊，應排在中段或後段。
   - 若同族群核心股明顯更強，該股即使上漲，也要判斷是補漲機會，還是資金不認同。
   - 但若該股符合第 0 條，則可部分略過「非主流 / 非核心」扣分，並重新評估是否屬於早盤強攻、補漲轉強或題材重新定價。

請採用兩階段分析：

第一階段：快速掃描全部股票
- 每檔都盡量查最新資訊，不要只憑既有印象或歷史題材。
- 先判斷當天市場主流題材與資金集中方向。
- 再判斷每檔股票是否屬於主流族群、是否為該族群核心或次核心。
- 特別檢查每檔股票當日資金攻擊型態：
  - 是否開盤一字鎖漲停
  - 是否 09:10 前漲停
  - 是否鎖死到收盤
  - 是否盤中打開
  - 是否爆量開高走低
  - 是否放量長紅收高
- 排除題材不明、資訊不足、資金關注度低、只是沾邊、偏中長線但短線攻擊性不足的股票。
- 初步選出最有短線資金續推可能的 10～15 檔。

第二階段：深度比較候選股
請重點比較：
1. 題材是否為當下市場主流。
2. 是否為該題材 / 同族群內真正被資金偏好的股票。
3. 同族群內是否已有更強核心股，該股相對定位是核心、次核心、補漲、跟漲，還是資金不偏好。
4. 是否有營收、EPS、法說、訂單、漲價、轉單、毛利率修復、產品放量等數字驗證或預期差。
5. 法人、投信、外資、主力、融資、成交量是否支持。
6. 技術面是否放量突破、收在高點、漲停鎖死，或反而爆量開高走低。
7. 是否符合第 0 條「早盤極強鎖停」（09:10（含）前漲停，且漲停後一路鎖死至收盤）。
8. 隔日追價風險是否過高。

資金強度請用三層判斷：

第一層：中期資金趨勢
- 請比較近半年、近 60 日、近 20 日走勢。
- 若某股今天漲停，但近半年明顯落後同族群核心股，應先視為補漲或跟漲。
- 若某股前面已強很久，近期整理後再次突破，應視為整理後再攻，不要因短期整理而低估。
- 若某股同族群題材正確，但近期走勢長期落後核心股，代表資金可能不偏好，排序應降低。
- 但若該股符合第 0 條「早盤極強鎖停」（09:10（含）前漲停且一路鎖死至收盤），則需重新評估是否為補漲轉強、題材重新定價或資金重新選股。

第二層：當日資金攻擊
- 本層請完全參照上文核心排序原則「4. 當日資金攻擊強度要明確加權，但不能只看是否漲停」：依該條所列第 1～7 項之強度順序與各項附帶說明（含未漲停之放量長紅收高、盤中換手漲停與尾盤硬拉降權等）判斷當日攻擊力，不得僅以是否漲停或僅以收盤是否漲停作為依據。
- 符合第 0 條「09:10（含）前漲停且一路鎖死至收盤」者，適用第 0 條之排序加權（可高於當日無此等早盤鎖停之市場主流族群核心股）；不符合第 0 條者不得主張該加權。
- 若出現漲停打開收不回、爆量開高走低、長上影線、收盤未鎖住漲停或未守關鍵價等情形，依第 4 點第 7 項明顯降權，且不得套用早盤極強鎖停加權。

第三層：題材與續航
- 題材是否為當下市場主流。
- 是否為主流族群內的核心標的。
- 是否有最新營收、EPS、法說、訂單、漲價、毛利率修復等驗證。
- 若營收 / EPS 普通或年減，但有明確預期差、轉機修復、法人回補、族群輪動或題材重新定價，仍可提高評估。
- 但若只是基本面好，沒有資金攻擊，也不是主流族群核心，不能排太前。

請特別避免以下錯誤：
- 不要因為某股營收、EPS、法說好，就忽略它不是市場主流或族群核心。
- 不要把「題材有受惠」誤判成「資金會集中推高」。
- 不要把同族群的次核心 / 補漲股排在真正核心股前面。
- 但若次核心或補漲股符合第 0 條「早盤極強鎖停」，而核心股當日無此等型態，則可依早盤極強鎖停加權排在核心股前面。
- 不要因為公司是龍頭或基本面穩健，就直接判斷短線資金會推高。
- 若某股在同族群內漲幅明顯落後核心股，即使題材相同，也應視為資金不偏好或只是補漲。
- 若某股符合第 0 條（09:10（含）前漲停且漲停後一路鎖死至收盤，含開盤一字鎖漲停），不可只因它不是原本族群核心就機械式壓低排名，應重新評估是否為早盤強攻、補漲轉強或題材重新定價。
- 若某股不是主流族群，但符合第 0 條，可以排前面；但要標註它是純籌碼短打、早盤強攻股或非主流攻擊股。
- 若某股不是族群核心，當日漲幅也不強，不應只因題材或營收好排在前面。
- 不要只看「收盤是否漲停」，必須比較「漲停時間、是否鎖死、盤中是否打開、收盤是否鎖住」。
- 不要把 10:00 後才換手漲停的股票，機械式排在符合第 0 條（09:10（含）前漲停且一路鎖死至收盤）的股票前面，除非後者有明顯弱化訊號或題材續航極差。
